# Miau-Memory

Ein Katzen-Memory für kleine Kinder. Das Spiel läuft komplett im Browser, sendet keine Daten
und braucht nach dem ersten Laden kein Internet mehr.

**Auf dem Tablet installieren:** Diese Seite in Chrome öffnen, dann im Menü (⋮)
„Zum Startbildschirm hinzufügen“ → „Installieren“ wählen.

Dieses Repo wird automatisch erzeugt. Bitte hier nichts von Hand ändern.
